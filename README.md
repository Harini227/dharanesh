# Forever Brotherhood

React + Vite + Tailwind. Run locally: `npm install` then `npm run dev`.

## Replace the photograph
Overwrite `public/images/our-picture.jpg` with your photo (same file name, JPG). Nothing else to change.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. On vercel.com: Add New > Project > import the repo.
3. Keep the detected settings (Vite, build `npm run build`, output `dist`) and click Deploy.
